Стандарты ECMAScript

ES2026​

  • методы Uint8Array для работы с форматами Base64 и Hex
  • методы .getOrInsert() и .getOrInsertComputed() для Map и WeakMap
  • Math.sumPrecise() – точное суммирование чисел с минимизацией погрешности
  • Iterator.concat() – объединение нескольких итерируемых объектов
  • Array.fromAsync() – асинхронное создание массивов
  • Error.isError() – надёжная проверка объектов ошибок

Работа с JSON:

  • доступ к исходному тексту значения в JSON.parse()
  • JSON.rawJSON() – вставка необработанного JSON-представления
  • JSON.isRawJSON() – проверка raw JSON-объектов

ES2025​

  • глобальный объект Iterator и Iterator Helpers
  • методы Set для операций над множествами
  • Promise.try() – преобразование результата или синхронного исключения
  • тип Float16Array и связанные с ним методы у DataView и Math

Новые возможности регулярных выражений:

  • RegExp.escape() – экранирование строки для использования внутри выражения
  • inline-модификаторы флагов: /^--module=(?i:esnext)$/
  • повторяющиеся имена групп захвата в альтернативных ветках

ECMAScript Modules:

  • синтаксис Import Attributes: import ... with { ... }
  • поддержка импорта JSON-модулей

ES2024​

  • Promise.withResolvers() – создание Promise вместе с resolve и reject
  • Object.groupBy() и Map.groupBy()
  • методы строки .isWellFormed() и .toWellFormed()
  • флаг /v в регулярных выражениях: расширенная работа с Unicode-множествами
  • возможность изменения размера и передачи владения ArrayBuffer
  • возможность увеличения размера SharedArrayBuffer
  • Atomics.waitAsync() – ожидание изменения значения в разделяемой памяти

ES2023​

Методы Array и TypedArray для поиска с конца:
.findLast(), .findLastIndex()

Изменение Array и TypedArray через возвращение новой копии:
.with(), .toSorted(), .toReversed(), .toSliced()

ES2022​

  • метод .at() для Array, String и TypedArray
  • Object.hasOwn() – проверка наличия собственного свойства объекта
  • Error.cause – возможность указывать исходную причину ошибки
  • флаг /d в регулярных выражениях: начальные и конечные индексы совпадений
  • top-level await в модулях

Новые возможности классов:

  • приватные поля, статические поля, методы, геттеры и сеттеры
  • статические блоки инициализации: static { ... }

ES2021​

  • логические операторы присваивания: &&= , ||= и ??=
  • numeric separators: возможность разделять разряды чисел (1_000_000)
  • метод строки .replaceAll()
  • Promise.any() – выполнение при первом успешно выполненном промисе
  • новый тип ошибки AggregateError
  • WeakRef и FinalizationRegistry

ES2020​

  • оператор optional chaining: ?.
  • оператор nullish coalescing: ??
  • тип данных BigInt для целых чисел произвольной точности
  • метод строки .matchAll()
  • Promise.allSettled() – ожидание завершения независимо от результата
  • стандартизация порядка перечисления свойств в for...in
  • универсальный способ доступа к глобальному объекту через globalThis

ECMAScript Modules:

  • import() – динамическая загрузка ES-модулей
  • import.meta – метаобъект с информацией о текущем ES-модуле
  • export * as ns – реэкспорт всех экспортов под единым пространством имён

ES2019​

  • методы массива .flat() и .flatMap()
  • методы строки .trimStart() и .trimEnd()
  • Object.fromEntries() – создание объекта из последовательности пар
  • возможность опускать параметр в catch
  • специальное свойство description для Symbol
  • well-formed JSON.stringify(): обработка одиночных суррогатов Unicode
  • стандартизация .toString() для Function: сохранение исходного текста

ES2018​

  • rest-синтаксис при деструктуризации объектов
  • spread-синтаксис в литералах объектов
  • асинхронные итераторы и конструкция for await..of
  • метод .finally() для Promise

Новые возможности регулярных выражений:

  • именованные группы: (?<name>...)
  • lookbehind – проверка назад: (?<=...) и (?<!...)
  • поиск по Unicode-категориям: \p{...} и \P{...}
  • флаг /s: для . включает символы перевода строки

ES2017​

  • async / await – синтаксис асинхронных функций поверх Promise
  • Object.values() и Object.entries()
  • Object.getOwnPropertyDescriptors() – дескрипторы всех собственных свойств
  • методы строк .padStart() и .padEnd()
  • trailing comma в объявлениях и при вызове функций
  • SharedArrayBuffer и Atomics для безопасной работы с разделяемой памятью

ES2016​

  • метод массива .includes()
  • оператор возведения в степень: **

ES2015​

Синтаксис и конструкции языка:

  • let и const, цикл for..of
  • стрелочные функции, параметры по умолчанию, rest-параметры
  • оператор spread, деструктуризация массивов
  • литералы строк-шаблонов, Unicode-экранироваине
  • расширение литералов объектов, новые литералы чисел
  • классы, наследование и static
  • функции-генераторы и yield
  • модули: import / export

Новые механизмы языка:

  • протокол итерации
  • Promise – стандартный механизм асинхронных операций
  • Symbol, символьные ключи и well-known symbols
  • Proxy и Reflect
  • поддержка наследования встроенных типов

Новые встроенные объекты:

  • коллекции Map, Set, WeakMap, WeakSet
  • типизированные массивы (например, Uint8Array)
  • ArrayBuffer, DataView – работа с бинарными данными

Расширение существующих API:
Array, Object, String, Number, Math, RegExp, Function, Date.
