TypeScript

TypeScript — это язык программирования, являющийся расширением языка JavaScript со строгой типизацией. TypeScript компилируется в JavaScript.

Основная идея языка — расширить JavaScript статической типизацией и инструментами, которые делают разработку более предсказуемой, безопасной и удобной, сохраняя при этом совместимость с экосистемой JavaScript.

TypeScript был впервые анонсирован Microsoft в 2012 году, а в 2014 состоялся релиз версии 1.0. В 2026 году вышла версия 7.0, ключевым изменением которой стал полностью переписанный на Go компилятор, что обеспечило значительное ускорение сборки.
